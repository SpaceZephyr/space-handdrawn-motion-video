# 踩过的坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 手写字设了字号不生效 | `.hand` 自带字号，写在外层 div 上会被盖掉 | 用 `write()/hand()` 的 `size` 参数，它套在内层 span 上 |
| 斜线涂色画不出来 | rough.js 的 hachure 是描边，描边宽度传了 0 | `R.hatch` 已按 `fw`（默认 3）给宽度 |
| `box(x, y, 0, 0, …)` 里的东西挤成一列 | 宽度被设成 0px | 放「一块东西」用 `ON()`（不设宽度）；要固定宽度才用 `box` |
| 截图里的字看不清 | 整张 2880 宽的官网截图缩到 800 宽 | 用 PIL 裁出要讲的那块（列表、对话、清单）再 `pin()` |
| 白色 logo 在白板上看不见 | 官网 logo 多是白色透明底 | `logo(src, h, { ink: true })` 压成墨色 |
| 场景结尾东西没出完 | 最后一个动作挂在句末最后几个字 | 挂到句子中段的词；句间只留 0.45 秒 |
| 马克笔出现在截图、气泡上 | 给「贴上去」的东西用了 write 或 draw | 截图、气泡用 `up/pop/fade`；确实要画又不要笔时加 `pen: false` |
| `c.at()` 报找不到词 | 稿子里写的是 `{Grok Bot|格罗克波特}`，查的是读法 | `c.at()` 查字幕写法（花括号前半）；稿子改了词，scenes 里也要改 |
| 识别报「活儿 → 活」「波特 → BOT」 | Whisper 丢儿化、把英文读法写回英文 | 不用重配 |
| 官网抓不到正文 | Cloudflare 拦无头浏览器（x.ai 就会） | 换发布文章页、换时间再抓，或用搜索结果 + 已有截图 |
| init.sh 打印乱码 | bash 把 `$P（` 里的全角括号当成变量名的一部分 | 写成 `${P}（` |
| 调慢笔速（pace）后句末的字写不完 | 写字时长 × pace，挂在句末的动作越过了场景结尾 | `render.mjs` 会打印「第 N 场：… 才完」，把这些动作挂到句子中段的词上 |
| 英文产品名被念成别的（Grok Bot → Ruck Buck） | 英文 TTS 对生造词也不稳 | align.py 报出来后出 3–4 个种子候选，识别对的那个记进 `voice.seeds` |
| 双语字幕对不上 | say 和 sub 的竖线块数不一样 | build.mjs 会直接报错，补齐块数；一块一屏，英文 ≤ 8 个词 |
| 转场不在拍点上 | 没跑 beats.py，或换了配乐没重测 | 换曲后重跑 `beats.py` 再 build；`"beatSync": false` 关掉 |
| 手绘的手机、通知、消息框看着简陋，像草图 | 产品界面用线框画出来缺质感 | 一律换成真实界面剪贴：`cut()` `banner()` `sticker()`，没有官方图时用 `notif()` + 真实 App 图标 |
| 剪下来的界面字糊 | 从 X 的 720p 视频里截 | 同一条发布视频多半在 YouTube 有 4K，`yt-dlp -F` 挑最高格式，`cutout.sh` 按秒取原尺寸帧再裁 |
| yt-dlp 报 YouTube「page needs to be reloaded」 | yt-dlp 太旧 | `brew upgrade yt-dlp` |
| 抠完底色，界面里的浅色也被抠空了 | colorkey 相似度太大 | 从 `0.06:0.04` 起调；只抠纯色背景，界面本身的白卡放进 `banner()`/`cut()` 的白底里 |
| 水彩/水墨里手绘的眼睛、圆被晕成随机颜色 | 框和圈会自动晕淡彩 | `R.ell(..., { wash: false })` |
| echo 出来第一个字乱码 | `$OUT：` 全角冒号被当成变量名 | 写成 `${OUT}：` |
| 弹出动作差一点不在拍上 | 按关键词算的时间不在拍点 | `c.beat(时间)` 吸到最近拍点（窗口 0.35 秒，第三个参数 2 只吸每两拍） |
