# 例子：代码做视频的 9 种技术（16:9，3 分 33 秒，18 场）

讲解类：把一篇文章做成手绘讲解视频，每种工具配一段**演示动图**（右边大图）和一段**真实案例视频片段**（左下小图），都用 `clip()` 贴在白板上。

- 稿子：按文章结构写 18 句，`c.at()` 关键词都在稿子里原样出现。
- 演示动图：文章里的 9 张 GIF，用 `scripts/assets/clip.sh 动图.gif assets/clips/demo-xxx.mp4 0 "" 960` 转成全关键帧 mp4，播一遍停在最后一帧（动图从空白开始，所以不循环）。
- 案例片段：文章引用的 YouTube 视频，每段裁 3–6 秒，画面下写「真实案例 · 作者」。裁完抽最后一帧看一眼，别停在口播人脸或转场卡上。片段和截图不随仓库分发。
- 配音：yovoice Serena，speed 1.08；第 2、13 句换种子 23，第 11 句换 42（「规定」「分层」「3Blue1Brown」读错）；`{3Blue1Brown|three blue one brown}` 标了读法。
- 配乐：`pick-it-up.mp3`，-27 LUFS，转场卡拍点；`pace: 1.4`。
