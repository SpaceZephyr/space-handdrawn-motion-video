# 例子：Claude Duet 剪贴画宣传片（16:9，96 秒，14 场）

水彩白板 + 真实素材剪贴。画面里的界面、通知、人像、App 图标全是真实素材剪下来贴上去的，手绘只写标题、画箭头、圈重点。

- 素材来源：官方发布视频的 4K 版（YouTube，`yt-dlp -f 313`），用 `frames.sh` 拼总览挑帧，`cutout.sh` 按秒取原尺寸帧、裁一块、抠掉淡紫色底（`0xCCCADA:0.06:0.04`）；连接器墙和 App 图标来自官方发布文章配图；首屏图来自产品页。
- 用到的剪贴组件：`notif()` 开场五条 iOS 通知（真实 App 图标）、`banner()` 抠底的通知横幅、`sticker()` 抠出来的整台手机、`cut()` 聊天记录/看板/邮件、`photo()` 四位测试者的拍立得、`app()` 真实 App 图标。
- 英文旁白 `Ryan`，中英双语字幕；第 13、14 句换种子 42。
- 配乐 `cupcakes.mp3`（95.6 BPM，`bgmLufs: -20`），转场卡拍，通知、拍立得弹出用 `c.beat()` 吸到拍点上（32 个弹出里 30 个落在拍点 60ms 内）。
- 素材是第三方截图，不进仓库。复现时按 scenes.mjs 顶部注释重新剪到 `assets/ui/`。
